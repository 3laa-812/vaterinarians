# Project Structure & Architecture

## Tech Stack

| Layer | Choice | Why |
|---|---|---|
| Framework | Next.js 16 (App Router) | Full-stack, SSR, API routes, one repo |
| Language | TypeScript | Type safety across frontend + backend |
| Styling | Tailwind CSS + shadcn/ui | Utility-first, RTL-compatible |
| ORM | Prisma | Type-safe DB access, migrations |
| Database | PostgreSQL (Railway) | Relational, solid for this data model |
| Auth | NextAuth.js  | JWT, role-based, easy session management |
| Notifications | Novu | Multi-channel, dashboard, free tier |
| i18n | next-intl | Best RTL/LTR support for Next.js App Router |
| PWA | next-pwa + Workbox | Offline cache, installable, push-ready |
| State | Zustand (UI) + TanStack Query (server) | Minimal, predictable |
| Validation | Zod | Shared schemas frontend + backend |
| Charts | Recharts | Lightweight, composable |
| Scheduler | Vercel Cron Jobs | Free, reliable, no extra infra |
| Hosting | Vercel (app) + Railway (PostgreSQL) | Zero-config deploy |

## Middleware Logic

```
Request hits any route
  │
  ├── /api/* → skip middleware (API handles own auth)
  │
  ├── Not authenticated → redirect to /[locale]/login
  │
  ├── Authenticated:
  │   ├── role = SUPER_ADMIN → access everywhere
  │   ├── role = CLINIC_ADMIN → access own clinic only, no /admin/clinics write
  │   └── role = DOCTOR → no /admin/* access, own clinic data only
  │
  └── Locale detection:
      ├── Read user.preferredLang from session
      └── Redirect to /ar/... or /en/... accordingly
```

## RTL / LTR Strategy

- `next-intl` handles locale routing (`/ar/...` and `/en/...`)
- Tailwind `dir` attribute set on `<html>` based on locale
- All components use logical CSS (`start`/`end` not `left`/`right`)
- `tailwind-rtl` plugin enabled for automatic RTL flipping
- Arabic uses `Cairo` font, English uses `Inter`
- Language toggle saves to `user.preferredLang` via API call — persists across devices

## Offline Strategy (PWA Caching)

| Data | Cache Strategy | Why |
|---|---|---|
| Today's appointments | NetworkFirst | Must be fresh, but fallback if offline |
| Animal list | NetworkFirst | Same |
| Static assets (JS/CSS) | CacheFirst | Never changes between deployments |
| Session form submit | Background sync | Queue if offline, send when reconnected |

> Session saves are queued locally if offline → synced automatically when connection returns → doctor sees "محفوظ محلياً ✓" then "تمت المزامنة ✓"
